**Notes**

The potentials provided here were trained using the torchscript branch of CACE
(https://github.com/BingqingCheng/cace/tree/torchscript) to enable the generation of TorchScripted models.

While these potentials exhibit essentially the same timing trends as those trained with the current `main` branch, 
the `torchscript` branch is not compatible with the current main branch due to modifications required for TorchScript support.

For examples of trained water potentials compatible with the current `main` branch, please refer to:
https://github.com/BingqingCheng/LES-BEC/tree/main/water/fit/fit_version_1
